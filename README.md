# AI 语音助手使用说明

通过遥控器或 USB 麦克风向 Kodi 发出语音指令，也可以接入智能体进行对话。语音转文字、智能体和语音合成分别配置；首次安装时，智能体默认为“本地命令引擎”，语音转文字和语音合成默认关闭。

## 首次配置

1. 在 Kodi 中安装插件，允许其后台服务运行。
2. 打开插件设置 → **扫码配置与测试** → **扫码配置语音助手**。
3. 用与盒子处于同一局域网的手机扫码。使用电脑时，打开电视上显示的地址，输入六位配置码连接。
4. 按网页中的“音频输入 → 语音转文字 → 智能体 → 语音合成”依次配置，修改后按页面提示保存。

直接运行插件会显示按键使用提示，日常通过绑定的语音按键启动。

## 音频输入与按键绑定

先配对蓝牙遥控器或插入 USB 麦克风，再在网页的“音频输入”页选择对应设备：

| 设备 | 音频输入选项 |
| --- | --- |
| Ugoos UR01 / UR02 | Ugoos 遥控 |
| 腾讯极光遥控器 | 腾讯极光遥控 |
| 移动高清遥控器 | 移动高清遥控 |
| 华为 R22 | 华为 R22 遥控（按住说话） |
| Homatics B21 / B25 / RemoteG11 | Homatics 遥控 |
| USB 麦克风、2.4G 语音遥控 | USB 麦克风 / 2.4G 遥控 |

**先切换输入设备，再绑定语音按键。** 点击“绑定语音按键”，随后在电视的绑定窗口中按一下要使用的遥控按键。没有麦克风的遥控器也可以绑定按键，配合 USB 麦克风使用。

需要取消绑定时，点击“移除语音按键绑定”。Kodi 插件设置中也提供绑定和移除入口。若提示先关闭当前弹窗，请关闭后重试。

## 语音转文字

在“语音转文字”页选择识别方式：

- **sherpa-onnx（本地）**：选择本地识别模型，安装所需组件，等待页面显示“本地识别已就绪”。首次加载模型需要等待。
- **豆包流式语音识别（联网）**：按页面指引申请并填写豆包 API Key，保存后点击“测试豆包识别”。
- **Codex 订阅听写（联网）**：安装所需组件，点击“登录 Codex”完成授权。

选好后，在页面下方的“所需组件”中点击“下载缺少的组件”。也可以按列出的文件名自行下载，再通过“手动上传依赖（可多选）”一次上传多个原始文件；不要修改文件名或自行解压。下载、解压和校验均显示进度，等待组件就绪后再使用。

## 智能体

在“智能体”页选择：

- **本地命令引擎**：直接执行播放、音量、页面导航等明确指令，无需登录智能体账号。仍需配置语音转文字。
- **Codex**：选择登录方式。订阅方式点击“登录 Codex”并完成授权；兼容 API 方式填写服务地址、API Key 和模型，服务需支持 Responses API。
- **CodeBuddy**：先选择国内版或国际版，安装组件后点击“登录 CodeBuddy”，打开页面显示的官方链接完成授权，再刷新账号和模型。网页可查看剩余积分及模型倍率，0 倍显示为“免费”。

保存配置后，可使用页面上的测试按钮检查连接。需要代理时，在对应智能体下填写 HTTP 代理地址，用户名和密码分别填写。

按需设置 AI 权限档位和审批策略。一档包含本地命令支持的固定能力，包括播放控制、媒体搜索播放、打开页面与插件、系统操作和上传日志，AI 也可调用这些能力；二档额外允许修改设置和维护媒体库；三档开放智能体原生终端与文件操作。任务需要审批或补充信息时，在对话窗口中操作。

“对话 session 有效期”可选每次完整对话、每天或永久共用。选择“每次完整对话”时，退出对话后，下次输入开始新会话。

## 日常使用

轻按绑定的语音键开始说话，停顿后自动结束录音；也可按 **OK** 立即提交，按 **返回** 取消。华为 R22 需要按住语音键说话，说完松开。

识别出文字后会显示处理过程和回复。在对话窗口中再次按语音键可补充要求；选择“停止任务”可取消当前任务，返回键或“退出对话”结束对话。

选择“后台运行”可隐藏窗口并继续执行任务，任务结束后会显示通知。有后台任务时，第一次按语音键只恢复窗口，再按一次才开始收音。需要审批或回答问题时，窗口会自动回到前台。

常用指令：

| 用途 | 示例 |
| --- | --- |
| 搜索影视 | 库里有没有黑客帝国、搜索库阿拉丁、从库里搜索十八岁的天空 |
| 播放电影 | 播放阿拉丁、我要看爱你西蒙 |
| 播放电视剧 | 播放电视剧十八岁的天空 |
| 指定季 | 播放第二季百变大咖秀、播放百变大咖秀第二季 |
| 继续观看 | 继续播放、继续看电影、继续看电视剧、继续看电视 |
| 从头播放 | 从头播放阿拉丁、重新播放阿拉丁 |
| 播放控制 | 暂停、继续播放、停止播放、快进三十秒、跳转到十分钟 |
| 音量与字幕 | 声音小一点、静音、取消静音、打开字幕 |
| 直播电视 | 我要看CCTV1、播放央视一套、打开直播电视 |
| 打开插件 | 打开红果短剧、打开筛选、打开遥控器插件 |
| 系统操作 | 关机、重启系统、挂起、重启到安卓 |
| 上传日志 | 上传日志、提交日志 |

普通播放默认续播，明确说“从头”“重新播放”“再看一遍”才从头开始。出现候选列表时，用方向键和 OK 选片。完整指令见 [command.md](command.md)。

“继续播放”优先恢复当前播放或暂停的媒体；没有当前播放时，比较 Kodi 本地库、Emby 动态库与巨库的最近观看记录并续播。“继续看电影”“继续看电视剧”分别限定类型。记录并列或部分来源查询失败时，先显示候选供确认。

明确限定媒体库的搜索指令只展示选项，完全匹配也不自动播放。单说“搜索”不作为本地影视指令，例如“搜索最近的新闻”仍交给已启用的智能体。

暂停、继续、快进后退、音量、静音和字幕开关等明确的本地播放控制，只用小窗口执行，不打开大对话框。已经打开大窗口或需要 AI 判断的播放控制，成功后自动退出；操作失败、需要确认或选片时保留窗口。

## 媒体来源

默认先查 Kodi 媒体库，再查 Emby 动态库和巨库。在“智能体”页可分别开关“搜索 Emby 动态库”“搜索巨库”，也可调整两者的搜索顺序；这些设置在本地命令引擎下同样生效。

使用 Emby 动态库前，先安装并启用 Emby Next Gen，在其中完成服务器登录。使用巨库前，先安装、启用并配置巨库。直播指令需要 Kodi 已配置好 PVR 客户端和频道。

指定季播放支持 Kodi 媒体库和 Emby 动态库；巨库首次选剧或无法确定剧集时，会打开资源页面供选季、选集。

巨库私有库续播读取其当前用户的观看记录；在线内容由助手后台记录实际播放的资源与断点，之后可说“继续播放”“继续看电影”或“继续看电视剧”，也可重新播放同一片名恢复已记录的在线资源。在线记录从启用本功能后开始积累，助手后台服务需保持运行；只有能确认原资源和季集的播放才记录。私有库已看完一集时查找后续未看集；在线内容只有已确认播放列表里的下一集才自动接续，否则打开巨库选集。关闭“搜索巨库”会同时停止记录和使用巨库续播记录。

Emby 播放剧集时，会将选中集所在的整季加入播放列表，再从选中集起播；未指定季时也只加入该季，不追加其他季。

## 语音播报

在“语音合成”页开启 Matcha，安装所需组件后即可朗读中英文回复。

- **朗读范围**：默认仅最终回复，也可选择工作说明和最终回复；命令、脚本及文件操作详情不朗读。
- **播报相对音量**：默认 50%，在 Kodi 音量基础上调整播报音量。
- **停顿系数**：数值越大，句间停顿越长。
- **音频唤醒时长**：默认 1 秒；若喇叭容易丢失开头，可适当增加。
- **AI 修正多音字**：使用当前配置的智能体辅助校音，可能增加首句等待。

开始录音或媒体开始播放时会停止朗读。暂停电影后仍可听取 AI 回复。
